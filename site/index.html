💳

Plan Bridge

Use Claude Max, ChatGPT Pro or Gemini Ultra as the brain — no API key. CHODE drives the official CLI and mounts itself as an MCP server, so its tools, memory and safety rails stay in charge.

🥤

The Gulp

chode import pulls rules, skills, commands, agents, MCP servers, permissions and hooks from Claude Code, Codex, Cursor, VS Code, Antigravity, Gemini CLI, Windsurf, Cline, Continue, Copilot and more.

📐

ORDER

Every repo gets a README, an ABOUT.md with story + marketing copy, LICENSE, CHANGELOG, tests, CI, backups and clean commits. Scored 0–100, from "flat" to "tuna can".

🧠

Memory + conscience

Reads CHODE.md / AGENTS.md / CLAUDE.md natively. Remembers facts, decisions and preferences across sessions. Keeps a ledger of risky moments and a conscience file it updates from experience.

🔎

Local RAG

A stdlib BM25 index of your codebase so the model reads only what matters. Fewer tokens, fewer dollars, better answers.

🖥

The Deck

A zero-dependency browser GUI: streaming chat, diffs, permission buttons, ORDER score, todos, memory. Localhost only, token-protected.

🚀

Ship & release

/ship writes the commit, refuses secrets, pushes, creates the GitHub repo. /release bumps, tags and publishes. Hugging Face too.

🛡

Safety without a nanny

Four modes. Dangerous commands need a typed yes. Deny lists. Secrets redacted and never committed. Everything in the ledger.

🆓

Free & offline

Ollama, LM Studio, llama.cpp — any OpenAI-compatible server. Nothing leaves your machine. One dependency. MIT.
